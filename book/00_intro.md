# Introduction

Welcome to `Applied AI: Build an Notion style AI based language learning app`. In this course you will learn the fundamentals of frontend engineering and applied ai by building notion style ai based language learning app.

## Who is this for

This is an advanced course. This course is ideal for intermediate to advanced learners looking to up their software engineering skills.
Experienced Software Engineers can also benefit from this course. You will pick up new tricks that will help speed up your workflow.
Recent Bootcamp graduates will also benefit from this course


## What will you learn in this course

1. What is/isnt Software Engineering?
2. How to think like a Product
3. The importance of Accessibility
4. How to build frontend applications using NextJS
5. How to build notion like app using tip tap
6. How to integrate AI into your application
7. How to deploy to AWS using AWS Amplify
9. What is a Techical Debt (There are 6 main kinds: v1, test data, tech, ai, doc and process)
